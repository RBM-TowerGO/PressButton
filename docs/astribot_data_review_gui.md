# Astribot 本地图形数据审核工具使用指南

本工具用于回放、筛选、裁剪和排列 Astribot 真机 HDF5 轨迹，并导出连续编号的数据集。所有操作都可以在桌面窗口完成，不需要连接机器人。

## 1. 打开工具

在终端执行：

```bash
cd /home/js/robot/VLA/PressButton
./scripts/review_astribot.sh gui
```

也可以从任意目录执行完整路径：

```bash
/home/js/robot/VLA/PressButton/scripts/review_astribot.sh gui
```

本机应用菜单中也可搜索 **Astribot 数据审核** 打开。
运行环境已经安装，无需手动激活虚拟环境。请在工作站图形桌面中启动；普通 SSH 终端不一定具备显示窗口的环境。
更新工具代码后，需要关闭旧窗口并重新打开才能使用新增功能。

## 2. 默认数据和保存位置

以下路径均相对于 `/home/js/robot/VLA/PressButton`：

| 内容 | 路径 |
|---|---|
| 原始 HDF5（本批 102 条） | `data/astribot_s1b_20261025/storage/trans/hdf5_output_elevator1/` |
| 审核结果、裁剪范围、轨迹顺序 | `data/astribot_s1b_20261025_review/review.json` |
| 导出数据 | 在界面的导出对话框中指定 |

原始 HDF5 不会被删除或覆盖。重新打开工具会读取已有审核结果和顺序。
请只打开一个窗口处理同一份审核清单，避免与命令行工具同时修改。

## 3. 回放和切换轨迹

左侧列表显示顺序、原编号、审核状态和帧数。可以点击一条轨迹，也可以按状态筛选或搜索原编号。

| 控件 | 使用方法 |
|---|---|
| 上一条 / 下一条 | 按当前左侧列表切换上一条或下一条轨迹 |
| 下一条自动播放 | **默认勾选**；点击下一条并完成加载后自动播放。取消勾选则停在首帧 |
| 播放 / 暂停 | 控制当前轨迹回放 |
| ◀ 帧 / 帧 ▶ | 查看上一帧或下一帧 |
| 倍速 | 选择 0.25、0.5、1.0 或 2.0 倍速 |
| 时间滑块 | 拖动到指定帧 |
| 关节列 | 选择 0～24 列，比较蓝色实测曲线与橙色指令曲线；点击曲线可以跳帧 |

头部、左腕和右腕图像同步显示。画面下方显示当前帧、相对时间和关节指令时间偏差。
“下一条自动播放”仅作用于下一条按钮；上一条和直接点击左侧列表仍停在首帧。
到最后一条后点击下一条不会循环到开头。

## 4. 保留、删除和恢复

| 按钮 | 结果 |
|---|---|
| 保留 | 标记为保留，加入最终导出集合 |
| 将所有待审核项设为保留 | 顶部按钮，一次保留整个数据集中的待审核项，不受列表筛选影响；保留原来的裁剪范围、备注和顺序 |
| 删除 | 标记为已删除，从最终导出集合剔除，原文件仍然保留 |
| 恢复 | 恢复删除前的审核状态；没有历史状态时恢复为待审核 |
| 待排查 | 暂缓处理，不导出 |
| 重置为待审核 | 清除审核结论，恢复待审核状态 |
| 撤销 | 撤销本次窗口会话最近一次修改，最多保留 30 次历史 |

**最终只导出“保留”的轨迹。** 待审核、待排查、已删除均不会导出。
可以先删除不需要的轨迹，再点击顶部“将所有待审核项设为保留”。已删除、待排查和原有保留项不受影响；结构检查有错误或保留范围不足 2 帧的轨迹会跳过并提示原编号。时间偏差告警不属于结构错误，仍需要人工判断。批量操作自动保存，可点击一次“撤销”撤回本次批量标记。
结构检查通过不代表按钮按压成功，仍需人工回放确认。页面顶部的时间同步告警需要单独排查，导出不会自动修复。

## 5. 裁剪轨迹和填写备注

1. 播放或拖动滑块到想保留的第一帧，点击 **当前帧设为起点**。
2. 移动到想保留的最后一帧，点击 **当前帧设为终点**。
3. 也可以直接修改起始帧、结束帧数字，并填写备注。
4. 点击 **保存范围 / 备注**，再根据回放结果点击 **保留**。

图形界面的帧号从 0 开始，**起点和终点均包含**。例如起始 20、结束 179，保留 160 帧。
标记为保留时至少保留 2 帧。界面始终可以回看完整原轨迹，真正裁剪发生在导出时。
切换轨迹或正常关闭窗口时也会保存当前输入；保存裁剪范围不会自动把待审核项改为保留。

命令行与 JSON 使用的 `end_frame` 为不包含的上界，因此上面的界面范围会记录为 `[20, 180)`。界面会自动转换，无需手动编辑 JSON。

## 6. 调整顺序并重新编号

在左侧选中轨迹后，点击 **↑ 上移 / ↓ 下移** 调整顺序。建议切回“全部”查看完整顺序。
排序立即保存，但原始文件名和原编号不会改变。导出时按此顺序取出所有保留项，再从 0 连续编号。

例如保留项依次为原编号 `8、3、12`，导出后为：

```text
episode_000000.hdf5  ← 原编号 8
episode_000001.hdf5  ← 原编号 3
episode_000002.hdf5  ← 原编号 12
```

## 7. 导出整理后的数据集

1. 点击顶部 **导出保留项并重新编号…**。
2. 选择父目录，例如 `/home/js/robot/VLA/PressButton/data`。
3. 输入一个尚不存在的目录名称，例如 `astribot_s1b_reviewed_v1`。
4. 等待底部进度提示和导出完成弹窗。

输出结构如下：

```text
astribot_s1b_reviewed_v1/
├── episodes/
│   ├── episode_000000.hdf5
│   └── ...
├── episode_mapping.json
└── review_snapshot.json
```

`episode_mapping.json` 保存新旧编号、原文件路径、裁剪范围、SHA-256 和校验结果；`review_snapshot.json` 保存此次导出的审核清单快照。
导出会同步裁剪图像、状态、指令和时间戳，并逐帧解码检查。已有输出目录不会被覆盖。
导出期间可以查看数据，但不能修改审核决定或关闭窗口；等待完成即可。
**输出仍是 Astribot HDF5，不是 LeRobot 格式。**

## 8. 常见问题

- **删除后文件还在**：这是正常行为，删除是审核标记。只有导出的新数据集会排除该条，原始备份保留。
- **点导出提示没有保留项**：需要点击“保留”；仅查看、裁剪或删除其他轨迹不会自动保留剩余项。
- **想重新审核已删除项**：筛选“已删除”，选择轨迹并点击“恢复”。
- **下一条没有自动播放**：检查“下一条自动播放”是否勾选，并等待加载完成。点击左侧列表不触发自动播放。
- **提示审核文件被其他程序修改**：关闭窗口并重新打开，读取最新清单，不要同时运行多个编辑实例。
- **找不到新加的按钮**：关闭旧窗口，重新执行启动命令。

更多安装、Rerun 回放、命令行和新批次扫描说明见 [数据审核技术说明](astribot/data_review.md)。
