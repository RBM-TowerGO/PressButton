## P1 实测

环境为 RTX 5090 32 GB，驱动 580.95.05、PyTorch 2.7.0+cu128、Transformers 4.57.0，使用已有 `.venv-astribot-inference`，未修改该环境。完整依赖快照保存在 `outputs/s1b_deployment/environment_20261026.txt`。已有其他 GPU 进程未被停止；两份最终评估顺序运行。

| 指标 | step 2000 | step 8000 |
|---|---:|---:|
| 原验证集固定 anchor | 48 | 48 |
| 模型加载（含身份校验/导入/构造） | 51.979 s | 53.315 s |
| 首次推理（冷启动） | 226.68 ms | 226.56 ms |
| 额外 warmup / 正式计时次数 | 20 / 200 | 20 / 200 |
| 推理 p50 | 45.44 ms | 45.42 ms |
| 推理 p95 | 45.96 ms | 45.88 ms |
| 推理 p99 | 46.60 ms | 46.21 ms |
| 峰值分配显存 | 9.656 GiB | 9.656 GiB |
| 手臂 7 维 MAE | 0.0156355 rad | 0.0188362 rad |
| 夹爪准确率（48×7） | 93.15% | 97.32% |
| 直接调用 / HTTP 最大绝对差 | 0 | 0 |

所有输出均为有限 `(7,10)`，逐维 MAE 与 7×10 的逐 horizon 误差保存在机器可读报告。每次性能采样记录 iteration、anchor ordinal、episode、frame、seed。GPU 计时在调用前后同步；覆盖模型内部 processor 和预测，不含 reader 解码、外部 224 缩放及网络。HTTP RTT 和服务端预处理/推理耗时单独保存；不能将本表视为机器人端到端延迟。

真实尺寸 head 1280×720 和 right 640×360 的 RGB 经 PIL BILINEAR 缩放，与训练 reader 的图像逐像素一致。两份模型均在同一真实输入和 seed=42 下检查 policy/HTTP 一致性，容差固定为 **0**。HTTP 检查在 48 个 anchor 之后，因此是首次 HTTP 请求，但不是模型冷启动。原验证 anchor 使用训练评估相同的 seed 公式 `42+500000+episode*100003+frame`。

本地 BF16 指标与 HPC 原报告并非逐位一致（例如 step 8000 的原夹爪准确率为 97.02%），这里报告本机全部样本的实际结果，未调整一致性阈值。离线 MAE 和近常量头部预测不能证明真机按键成功率或主动头部控制能力。
