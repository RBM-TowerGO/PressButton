从项目根目录执行：

```bash
.venv-astribot-inference/bin/python scripts/start_s1b_inference.py --checkpoint 2000
```

代码为 `src/pressb/s1b_deployment/executor.py`、`robot_state.py`、`scripts/s1b_execute.py`；局部试验配置为 `configs/s1b_execution_p4_v1.json`。SDK 仅在显式 real-enable、现场人员/急停条件和状态检查通过后导入、构造。

- 位置硬参考来自本机 SDK URDF/夹爪 YAML。右臂下限 `[-3.1,-1.53,-3.1,-0.06,-2.56,-0.76,-1.53]`，上限 `[3.1,0.46,3.1,2.61,2.56,0.76,1.53]`；头部为 ±1.57、±1.22 rad；夹爪目标为 0～100。
- 局部目标窗口保留为初始审计姿态附近 ±0.02 rad，夹爪 0～100。目标变化速率为臂/头 0.03 rad/s、夹爪 50 SDK units/s，另有逐次变化和目标/反馈偏差限制；这些是局部工程约束，不是完整工作空间标定。
- 整条目标先检查 shape、有限值、位置、变化量、速率、反馈范围和状态新鲜度；任一失败不部分下发，也不静默裁剪。gripper 模型解码仍为 0.5 阈值；本次端点试验使用显式预定义连续轨迹，不把它伪装成模型输出。
- 命令看门狗为 100 ms，独立线程检查。stop 置锁存状态、停止 SDK 再记录；新输入不能自行恢复。实际使用 SDK 的 stop/is_stopped 和同步释放控制权方法，避免 SDK 50 ms 异步交接计时器与节点销毁竞争。
- 独立 StopObserver 在网络调用阻塞时继续验证反馈：连续 100 ms 满足速度和位置稳定条件，预算 250 ms。不能仅用 API 返回时间当作机械停止时间。

- 躯干、左臂、左夹爪、底盘均持续监视，漂移未超过预设门槛。SDK 调用节拍为 250 Hz，不把它当作底层电机伺服频率证明。

| 停止试验 | 停止请求至连续稳定条件确认 | 结果 |

| 命令看门狗 | 138.80 ms | FAULT，释放 |
