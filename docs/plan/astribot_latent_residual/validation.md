## 2. GPU 冒烟与学习稳定性试验

GPU 冒烟必须贯通真实相机、冻结推理、GPU 物理执行、replay 写入、至少一次梯度更新、checkpoint 保存恢复和确定性评估。记录 token/latent 形状、模型 hash、内存、请求/控制时间与异常。预算可沿用现有 smoke 的短回合和小 batch；报告必须标注为工程验证，不作为收益证据。

通过契约与 GPU 冒烟后，A/B 每组执行 10k chunk transitions，warmup=5000，使用首个计划种子 20261024，其他设置与正式实验一致。检查有限值、正常更新、正确恢复、吞吐和资源余量。不得仅根据短试验成功率低就否定方法，也不能以训练成功率高替代验证。

正式实验重新初始化，不继承 10k 试验网络、优化器或 replay。若试验导致配置变化，应记录版本，按新协议验证两组。

## 3. 正式 A/B 对照

- **A：** `state_only`，现有 q/qd＋基座动作残差 SAC。
- **B：** `state_latent`，相同设置＋处理后的 latent。

两组使用同一代码版本、相同场景/随机种子规则与训练配置。唯一计划中的学习输入差异是 latent 及必要的输入层宽度；B 的末帧附加推理单独计时。历史基座 23/40、第三轮 25/40 只提供背景，不替代本次 A 组。

| 参数 | 计划值 |
|---|---|
| 基座 | 冻结 VLA-JEPA step 8000 |
| 正式预算 | A/B 各三种子，每次 100k chunk transitions |
| 训练种子 | 20261024、20261025、20261026 |
| warmup / batch | 5000 / 256 |
| actor / critic LR | `1e-5` / `3e-4` |
| SAC alpha | 固定 `0.005`，不自动调节 |
| pre-tanh 均值正则 | `1.0` |
| 残差尺度 | 右臂各关节 `0.01 rad`，夹爪 `0.025 rad` |
| gamma / shaping | `0.995` / `1.0`，沿用实际控制步折扣 |
| 回合上限 | 40 秒仿真时间 |
| 数据划分 | 冻结 train-320 训练，val-40 开发比较 |
| 相机 | 训练头部＋右腕两路，评估原生七路；两组相同 |
| 物理与推理 | GPU 物理，推理期间物理暂停，原同步协议 |
| 评估策略 | 确定性残差，每种子最终预算 checkpoint 的 val-40 |

预算单位是 chunk transitions，不是 episode、30 Hz 控制步或梯度更新次数；同时记录实际控制步与 updates。每个种子在相同验证场景及基座请求 seed 规则下配对。分支行为导致后续轨迹不同是算法结果，不要求训练后的动作轨迹相同。

每组独立输出目录，保存协议、源码版本、checkpoint、训练指标、逐回合报告和评估汇总。已有目录不得覆盖。评估完成数不足 40 时报告不完整，不能把缺失场景记成成功或默认为物理失败。

test-40 不参与调参和本轮默认验收；方案固定后的最终比较另行安排。正式运行的 GPU 分配和实际吞吐记录在运行协议中，不直接引用旧 PiPER 并行吞吐作为本实验性能。

## 4. 指标与判定

### 4.1 必须报告

- 各种子 A/B 的成功数、成功率与差值；配对均成功、均失败、改善与退步数。
- 每种子的精确 McNemar p；报告不确定性，不只汇报最好的种子。
- 成功耗时、异常接触、失败类别、残差幅度和饱和比例。
- 推理、环境、更新、末帧附加请求、保存及总 wall time。
- 基础设施失败及重启/恢复记录，单列于物理失败。
- 内存、checkpoint 大小、训练/评估实际参数与计划偏差。

残差饱和诊断按归一化输出绝对值 ≥0.99 的分量比例统计，A/B 使用相同规则。成功耗时只在成功样本上统计，并同时报告成功数，避免不同成功集合造成误解。

### 4.2 不确定性与结论边界

逐种子报告配对差异及精确 McNemar；跨种子同时给出均值、范围和每种子明细。若报告合并置信区间，应保留场景聚类与 A/B 配对结构，例如对场景 ID 整组重采样，保留该场景各训练种子的结果；标明该区间反映的是给定训练种子下的场景不确定性。不能把三个种子上的重复 40 场景当成 120 个完全独立场景，也不能用三个种子宣称充分刻画训练随机性。

工程完成以契约与运行验收为准，不设任意成功率门槛。算法结论区分“收益有支持”“证据不足”“出现退化”，结合种子一致性、区间、配对检验及异常接触，不以单一 p 值或训练成功率作结论。

## 5. 已知风险诊断

| 风险 | 记录什么 | 本阶段处理 |
|---|---|---|
| 有界 Q 与塑形回报 | Bellman target 分位数、超出 `[0,1]` 比例、Q 接近边界比例 | 保留 critic 输出，不顺便改无界 Q |
| 塑形目标分布 | 折扣 return 与 target，区分未折扣 shaping_total | 不用 shaping_total 单独证明 Q 超界 |
| 终止势函数 | 成功/失败/timeout 的末帧势函数和 bootstrap 设置 | 保留目标，单列潜在偏差 |
| 距离代理 | finger body 原点距离与实际接触指标关系 | 不解释成真实表面间距，不在本轮换奖励 |
| 折扣单位 | 实际执行步数与 `gamma^steps` | 不把 chunk 和控制步 gamma 混用 |
| 特征/恢复异常 | 非有限值、服务身份、缓存与时序 | 停止并诊断，不伪造数据 |

出现非有限值、持续基础设施错误或严重学习异常时停止并保留证据。任何奖励、critic 输出或 bootstrap 修正必须采用新版协议，重新运行 A/B，不能混入当前结果。
