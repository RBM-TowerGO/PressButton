## 2. 10k稳定性检查及阶段门槛

A/B各从头收集精确10000条chunk transition，种子20261024，warmup=5000、batch=256，其余训练配置与正式阶段一致。warmup只收集、不更新；达到门槛后按当前runner的回合采集/集中更新方式训练，最终各10000次更新。每次更新从经验池随机抽batch，经验可重复使用。

检查有限值、实际预算、持续更新、Q/梯度与饱和诊断、吞吐和资源余量；完成后通过真实runner恢复learner、优化器和replay，再核对预算和指标。两组都通过才生成`trial_gate.json`并进入正式阶段。短期成功率低不单独判失败，训练成功率高也不能替代验证。

当前严重学习异常停止规则：连续3个batch出现critic总梯度为0且loss>1e-6，或某critic精确边界比例为1且该batch的target最小值>1e-6、最大值<1-1e-6。触发后写`learning_error.json`并保留checkpoint；基础设施错误单列。非有限值、错误标记、实际预算不符或源码身份变化均阻断后续阶段。边界比例和target越界等其余风险继续记录，不擅自修改奖励或Q输出。

正式训练重新初始化actor、critic、target、优化器和replay，不继承10k状态。任何训练配置修订均需记录协议并重新验证相应A/B。

- A：`state_only`，q/qd＋基座动作残差SAC。
- B：`state_latent`，相同设置＋处理后的latent。

| 参数 | 本轮值 |

| actor / critic LR | 1e-5 / 3e-5 |
| critic初始化 | 两组均显式`fan_in` |
| SAC alpha | 固定0.005，不自动调节 |
| pre-tanh均值正则 | 1.0 |
| 残差尺度 | 右臂各关节0.01 rad，夹爪0.025 rad |
| gamma / shaping | 0.995 / 1.0，按实际控制步折扣 |
| 回合上限 | 40秒仿真时间 |
| 数据划分 | 冻结train-320训练，val-40工程比较 |
| 相机 | 训练头部＋右腕，评估原生七路 |

实际提交数与replay留存数都须精确等于预算；预算停止通过下一真实请求补齐最后后继，不额外执行chunk，也不记成物理timeout。独立保存两组产物，不覆盖历史目录。每组完成数必须为40，验证场景ID须与冻结val划分一致，缺失场景报告为不完整。test-40不参与本轮。
