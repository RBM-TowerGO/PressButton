# VIB-820 随机站位验证

创建日期：2026-10-13（Asia/Shanghai）。状态：正式30/30回合完整执行，25完整成功、5动态自碰撞；结果和验收已记录。

本阶段已完成 **30 个随机站位验证回合**，统计可达率、按压成功率和碰撞情况，为后续专家数据采集验证站位范围。第 20 回合中期结果已保存。扩大采集门槛未通过，下一步先修复去工作起始位姿的碰撞路径。

用户最终确认的范围为：以现有站位为中心，**前后、左右分别独立随机 ±20 cm**；高度和朝向不变。该要求替代之前建议的 ±5 cm。不可达、碰撞和运行失败均保留，不能重新抽样替换。
