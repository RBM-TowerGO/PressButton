# 指标与记录口径

以下是待实现的统一口径。所有概率均报告 `分子 / 分母 = 百分比`；分母为零写 `N/A`。未知值写 `null` 并记录原因，禁止填成失败、成功或零碰撞。

## 1. 每个样本的最小记录

| 类别 | 字段/含义 |
| --- | --- |
| 身份 | batch_id、sample_id、attempt_id、seed、代码/配置哈希 |
| 站位 | nominal_xyz、delta_xy、requested_xyz/yaw、实际初始变换及坐标系 |
| 预检查 | 每个关键位姿 IK pass/fail/unknown、残差、关节限位结果；初始重叠 pass/fail/unknown |
| 执行 | motion_started、press_phase_started、终止阶段、仿真时长、物理步数、退出码 |
| 按压 | press_triggered、最大行程、最大接触力估计、释放状态、锁存/清灯状态 |
| 碰撞 | 禁止接触是否发生、监测覆盖状态、首个接触时间/对象/阶段、最大力估计 |
| 完整性 | 轨迹路径、审计结果、缺失字段、运行错误、日志/视频路径 |
| 结论 | primary_outcome、failure_flags、full_success |

按 120 Hz 保存原有 `q/qd/target/tip/travel/force/light/base/base_quat/phase/epoch/time/simulation_time`。控制目标是关节位置目标；接触力是仿真接触冲量换算值，不是实测传感器标定值。

## 2. 可达率

- `N_planned`：清单内正式随机样本总数，排除名义站位冒烟回合。
- `N_ik_pass`：工作起始、接近、目标按压三个关键位姿全部 IK 通过。
- `N_ik_fail`：至少一个关键位姿明确 IK 失败。
- `N_ik_unknown`：尚无明确失败且未能完成全部关键位姿检查。
- 必须满足 `N_ik_pass + N_ik_fail + N_ik_unknown = N_planned`。

**关键位姿可达率** = `N_ik_pass / (N_ik_pass + N_ik_fail)`；同时报告检查覆盖率 `(N_ik_pass + N_ik_fail) / N_planned` 和已确认可达占全部样本的比例 `N_ik_pass / N_planned`。

该结果只反映冻结的 IK 求解器、种子策略和限位条件；求解失败不等于数学上不存在任何解。不能把此比例命名为“全路径无碰撞可达率”。执行中的 `path_ik_failed` 单列数量与站位，不回写已通过的关键位姿结果。

## 3. 按压成功率与完整回合成功率

有效按压触发要求：**同一物理步**目标按钮行程 ≥1.0 mm，且目标按钮与指定指尖接触力 >0.02 N。不能把不同时间的最大行程与最大力拼成一次成功，也不能只凭灯亮或视频判断。

- `N_attempted`：已经进入物理运动流程的样本，包含合爪/接近失败，防止只统计到达按钮的回合。
- `N_press_confirmed`：通过有效轨迹确认发生有效按压触发的样本。
- **尝试按压成功率** = `N_press_confirmed / N_attempted`。已开始但崩溃、轨迹缺失的回合留在分母，属于未确认成功，并另列数据未知数量；不将其描述成已证实的按压物理失败。
- **全体样本按压成功比例** = `N_press_confirmed / N_planned`，体现不可达、初始碰撞和启动失败的影响。
- `N_full_success`：按压、释放、返回、复位、禁止碰撞与数据审计全部通过的样本。
- **完整回合成功率** = `N_full_success / N_planned`；必要时附 `N_full_success / N_attempted`。

完整成功还要求：撤回后行程 <0.3 mm；无误触；返回工作起始关节误差 <0.025 rad；按钮锁存在有效触发后持续，复位后熄灭；行程不超过 2.2 mm（2 mm 行程 + 0.2 mm 审计容差）；现有 FK、固定底盘、非活动关节及时间轴检查通过。

按压触发后又发生碰撞的回合可以计入 `N_press_confirmed`，但不能计入 `N_full_success`。两者必须分开报告。

## 4. 碰撞统计

分别报告初始禁止重叠与动态禁止接触，保留几何查询和接触力监测的不同含义。

现有动态规则：机器人相关接触的力估计 **>0.1 N** 才计入非预期接触；当前激活按钮与指定指尖接触允许，指定对向指尖互相接触允许；资产另有相邻连杆碰撞过滤。实施前核对并记录完整过滤表。不能为了提高成功率把手臂与面板、门框或墙面的接触加入白名单。

每个样本动态状态三选一：

- `collision`：至少观察到一次禁止接触，即使随后中止也已确认为碰撞。
- `clear`：整个要求监测的运动流程有完整覆盖，未观察到禁止接触。
- `unknown`：未运行、监测不完整或提前中断，且尚未观察到禁止接触。

**动态碰撞率（已判定样本）** = `N_collision / (N_collision + N_clear)`；必须同时报告判定覆盖率 `(N_collision + N_clear) / N_planned`，以及已开始运动但仍未知的数量。不得把未执行样本或监测缺失样本当作无碰撞。初始禁止重叠率同理按已完成初始查询样本计算，并报告查询覆盖率。

禁止接触事件条数与发生碰撞的回合数分别报告。相邻多个物理步可能是同一次接触，不能把 callback 条目数称为独立撞击次数。碰撞明细至少保留对象对、阶段、时间/步号及力估计。

结论写“在所记录的碰撞过滤规则和 >0.1 N 阈值下未检测到禁止动态接触”，不能据此声称绝对无接触。低于阈值的接触与未覆盖的几何穿插不在这个动态指标的保证范围内。

## 5. 终态与失败分类

每个样本保留一个主终态，另用 `failure_flags` 保存重叠问题。主终态按最先阻断流程的原因决定，不用后续审计缺失覆盖已经确认的碰撞事实。

| 主终态 | 含义 |
| --- | --- |
| success | 完整成功并通过独立审计 |
| initial_collision | 初始站位禁止重叠 |
| target_ik_failed | 关键位姿 IK 未通过 |
| path_ik_failed | 执行轨迹中 IK 失败 |
| unexpected_contact | 动态禁止接触 |
| press_not_triggered | 已完成按压尝试但未触发 |
| release_or_return_failed | 触发后释放或返回失败 |
| reset_failed | 复位未通过 |
| audit_failed | 其他明确的物理/数据一致性检查失败 |
| runtime_error | 启动、超时、进程崩溃等基础设施/运行错误 |
| pending / running | 尚未终结，只能存在于中期/中断报告 |

汇总应满足：各主终态样本数之和等于 `N_planned`，CSV 行数等于 `N_planned`，重试不增加唯一样本数。失败标志计数允许重叠，不能与主终态合计混用。

本阶段只有 20–50 回合，用于排查和判断下一步范围。零次观测碰撞也不能证明其他站位或更多运行一定无碰撞。
