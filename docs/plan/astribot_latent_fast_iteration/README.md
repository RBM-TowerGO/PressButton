## 目标与当前证据

优先让关闭探索后的确定性策略救回失败场景。采用一个训练种子 `20261024`，不要求多种子、显著性检验、每轮完整 A/B，也不预设必须执行完所有阶段。有效候选优先追加预算，失败候选及时停止。

| 证据 | 已确认的事实 | 不能据此认定 |
|---|---|---|
| 原 A/B 正式训练及验证 | 各 100k transitions，均 24/40 成功，而且成功场景完全相同 | latent 永远没有收益 |
| B 最终模型离线检查 | 2,048 条 replay 观测上，确定性手臂残差 RMS 约 0.00202°，采样约 0.3404°，相差约 169 倍 | 训练收益已经证明全部来自随机探索 |
| 偏移诊断 | 受控水平 MAE 加 latent 后从 2.894 降至 0.829 mm；仿真闭环接触前 latent-only 可解码偏移 | 融合策略已学会有效纠错 |
| critic 历史修复 | 正式训练采用 fan-in 与较低 critic LR，旧版整体梯度坍塌已修复 | critic 对细小修正有正确的价值梯度 |

依据：[最终配对结果](../../../outputs/astribot_online_rl/latent_fixed_campaign_20261022/run/paired_results.json)、[B 离线残差检查](../../../outputs/astribot_online_rl/latent_diagnosis_20261023/offline_probe.json)、[critic 修复记录](../astribot_latent_residual/critic_diagnosis.md)、[偏移诊断报告](../../results/astribot_latent_offset_probe_20261023.md)。`outputs/` 是本地产物，未纳入 Git；在无产物的克隆中这些链接不可用。

均值正则压制、critic 动作辨别不足、动作维度过高，均是待验证假设。离线融合探针的标准化失稳不是原 B 已确认的问题；已审核恢复的推理连接中断也不是已确认的无收益原因。旧计划部分段落仍是历史运行快照，最终状态以配对产物为准。

## 固定设置与初始化契约

- 冻结原 VLA step 8000；B 输入保持实际使用的 2048 维均值池化、逐样本 LayerNorm latent。训练种子 `20261024`，执行采样种子 `20261024`、`20261025`，分别记录环境种子与残差采样种子。
- 基准配置：critic `fan_in`，critic LR `3e-5`，actor LR `1e-5`，batch 256，固定 alpha `0.005`，均值正则 1，shaping 1，gamma `0.995`，手臂尺度 `0.01 rad`、夹爪 `0.025 rad`。具体 8 维顺序继承来源契约。训练、评估均 40 秒，保留原成功、异常接触和终止判定。
- 训练与开发评估优先原有头部＋右腕相机；完整 val-40 使用原生七相机。首次执行前确认 VLA 仍接收同样两路图像，不能把渲染布局差异当策略变化。
- 原 B 来源：[训练目录](../../../outputs/astribot_online_rl/latent_fixed_campaign_20261022/run/formal/state_latent_seed20261024/)，其中 `learner.pt`、`replay.npz`、`status.json`、`protocol.json` 只读。原 B 训练经验可复用，不导入其验证轨迹作训练。
- 新实验建议根目录 `outputs/astribot_online_rl/latent_fast_iteration_<启动时间>/`，每个候选独立子目录。保存来源文件 SHA-256、配置差异、新增经验数、在线更新数与离线更新数。
- **待新增接口：派生初始化。** 原 `--resume` 要求训练契约一致，不能通过改旧状态文件绕过。派生实验重置优化器和新计数，旧 replay 长度不计作新增经验，不触发旧 100k 的补齐更新。派生运行自身的故障恢复仍恢复自己的优化器和计数。
- 一次 learner 更新和一次 actor 更新不是同一口径；保留原 actor 延迟更新频率，并分别记录。结构变化时不要强行加载不兼容 actor 权重。

## 开发集、比较规则和停止规则

开发集从原 B val-40 按场景编号选失败前 8 个、成功前 4 个，已核对为：

- 原失败：`1, 62, 91, 97, 159, 180, 210, 217`。
- 原成功：`3, 9, 51, 52`。

固定以编号升序运行，保存清单。该集刻意偏重失败，不能用其成功率代表总体。原 B 历史参考为 4/12；阶段 0 重新测得的原 B 结果作为本轮统一参考，并保留两者差异。

候选开发集比本轮原 B 净增至少 2 次成功且异常接触不增加，优先追加；净增 1 次先复测候选和原 B，仍净增至少 1 次才追加。阶段 2/3 还必须优于其来源模型的开发集成功数，避免把继承收益算成新结构收益。若与来源持平，只保留备用，不继续扩预算。

只推进一个候选：按成功数高、异常接触少、共同成功场景仿真时间中位数低的顺序选择，仍相同则取改动较少者。每新增 5k 评估一次，连续两个检查点未超过本候选历史最好成功数则停止。最终保留最佳检查点，不强制选择最后一步。

最佳候选跑完整 val-40。工程投入门槛为至少 27/40、异常接触不超过原 B 的 1 次，再完整复测候选与原 B，仍有正的成功数差且异常接触不多于同期 B。没有足够预算复测时标记“初步改善，待复测”，不写通过。val-40 已参与开发，不声称独立泛化，本轮不使用 test-40。

NaN、现有连续学习失败门槛或基础设施故障触发即停止并保留证据，不盲目自动重启。阶段 0 没有发现随机优势不阻断后续；候选残差变大、梯度非零或偏移预测变好，都不能替代确定性成功率改善。
