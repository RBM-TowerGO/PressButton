# VIB-820 单按钮外呼面板与 S1 按压

采集与评估状态：本场景已用于 400 条专家数据采集、VLA-JEPA 微调与两轮闭环评估，见 [采集计划](plan/vib820_gpu_collection_400/plan.md)、[闭环评估](astribot_closedloop_20261018.md) 与 [配对对照](astribot_paired_val_20261019.md)。下文记录场景建模与单次物理验收。

按用户实测尺寸建立的第一版参数模型，场景位于电梯厅。目标是单个向下呼梯按钮，任务 ID 为 `0`；显示屏的上箭头和 `1` 是独立的静态外观参考，不表示要按的楼层。

| 金属门框边条横向宽 | 15 mm；含边条距离 215 mm |

面板顶部留边暂取 8 mm，因此模型顶边 / 底边为 1477 / 1077 mm；这两个安装高度由暂定留边推导，不能当成实测值。按钮与屏幕暂按面板横向居中。门洞宽采用实测 1.30 m，高仍暂定 2.15 m；墙体、地砖、标识位置、光照和机器人站位均为场景近似。标识为简化矢量绘制，不是现场照片贴图。

按钮质量 15 g、弹簧 300 N/m、阻尼 3 N·s/m、触发位移 1 mm、接触力阈值 0.02 N 是仿真暂定参数。用户测得的 2 mm 下陷量作为关节上限，不意味着已知电气触发点或真实力学参数。帽与外圈之间保留 0.3 mm 径向建模间隙以容纳接触容差。门框法向进深采用新增的 350 mm；横向 15 mm 仍表示金属边条宽度。

原始参考和实测表保存在工作区 `../panel_reference_vib820/`，不依赖在线素材即可运行。

## 材质升级（2026-10-13）

材质升级版本：[vib820_model_v4](../outputs/vib820_model_v4/)，
[模型包](../outputs/vib820_model_v4.zip)，
[前后对比](../outputs/vib820_model_v4/material_comparison.jpg)。

材质代码：`src/pressb/vib820_materials.py`；资产与可追溯来源：
[`assets/materials/vib820/README.md`](../assets/materials/vib820/README.md) 和同目录 `manifest.json`。

- 拉丝面板使用 ambientCG Metal010 的 2K 衍生颜色、粗糙度、OpenGL 法线；抑制原素材的大块污渍，保留低强度细纹。面板纹理竖向，反射具有各向异性；门和门框使用按世界尺寸投射的同源细纹。
- 白色墙体以白色背漆玻璃近似：不透明白底加介质反射表层，估计 IOR 1.52、表层粗糙度 0.028。显示窗采用黑底显示内容加玻璃反射表层。
- 标签保留 v3 的尺寸、色块和横纵位置，使用背印亚克力近似材质，估计 IOR 1.49、粗糙度 0.075，并添加无碰撞的 1.6 mm 薄板边缘。
- Poly Haven Large Corridor（2K HDR）提供室内环境反射，条形灯提供视频中类似的长条高光。该 HDRI 不是现场采集，真实电梯厅的反射分布仍为近似。
- 金属贴图和 HDRI 均为 CC0；NVIDIA 材质只引用 Isaac Sim 内置模块。导出目录中的图片均为相对路径，无在线素材依赖；完整 MDL 效果需要 Isaac Sim/Omniverse。通用 USD 查看器可使用附带的 UsdPreviewSurface 回退效果。

着色器的圆边和法线只改变外观，不使用几何置换。按钮几何、关节和力学参数沿用已验收版本。玻璃和亚克力采用涂层着色近似，未模拟透明板侧面折射；这些光学参数不能当成实测值。

验收：正面、斜视、环境三视角各输出亮/灭灯两张预览。独立 USD 对比确认 19 个物理对象的 131 个已写入属性及物理关系与 v3 相同（材质绑定与 UV 不参与物理比较）；9 个图片资产引用均可在输出目录内解析。相关 24 项测试通过。此轮未重复跑机器人按压，历史物理验收仍以 `vib820_press_v2` 为准。

## 几何与反馈

- 面板面片和固定外圈是带孔静态三角网格，碰撞近似使用 `none`，避免凸包封死按钮孔。
- 可动帽是独立圆柱刚体，通过沿 +X 的弹簧直线关节移动，范围 0–2 mm；箭头跟随按钮帽。
- 灯带和箭头白色发光，物理按压需同时满足指尖接触力与按钮位移；触发后保持亮灯，即使按钮回弹。
- 每回合清除呼梯请求；末尾验证物理 reset 后按钮回弹且请求清除。不模拟电梯调度、真实到站延迟或自动开门。
- S1 沿用原装闭合夹爪、固定底盘、静止躯干和左臂；没有额外按压杆。

渲染默认使用 RTX 实时模式；`--renderer PathTracing` 可选路径追踪。`--gpu 1` 可选择第二张显卡，此时需先使它可见（例如 `export CUDA_VISIBLE_DEVICES=0,1`）。

## 运行 S1 物理按压

```bash
python scripts/run_astribot_press.py --headless --video \
  --config configs/astribot_vib820.json --repeats 3 \
  --output outputs/vib820_press
python scripts/audit_astribot_press.py outputs/vib820_press
```

输出目录必须不存在。`--buttons 0` 可显式选择唯一的向下按钮；原 `--floors` 参数仍是别名，旧 24–35 场景的默认行为保留。报告中的 `button_ids` 给出轨迹数组的列顺序；旧报告无此字段时审计仍按 24–35 解释。

按压入口也支持 `--gpu 1`，需使第二张显卡可见（例如 `export CUDA_VISIBLE_DEVICES=0,1`）。
录像的 `capture_hz` 可在配置副本中设为 30；保持 `physics_hz=120`，物理触发和回弹检查仍使用每个物理步的读数。

独立审计检查真实位移与接触力同时成立、回弹、保持亮灯、单按钮数组、2 mm 行程限位、reset 清灯，以及固定底盘、夹爪闭合、归位和异常接触。一个固定站位的通过结果不代表实机验证或任意站位可达。
