# Astribot XYZ ±10 mm / 100k

本实验从头学习 7×3 笛卡尔残差，冻结 step 8000 VLA。观测为 state_latent_raw_command（2120 维），Actor 输入 2176 维、输出 21 维；Critic 输入观测、56 维基座动作与 21 维归一化残差，共 2197 维。目标熵为 −10.5。

动作在 astribot_torso_base 坐标系平移既有闭合手按压 TCP，姿态、夹爪及固定关节沿用基座。该 TCP 是工具参考点，不随夹爪开度改变。每轴 ±10 mm；整块按 1、0.5、0.25、0.125 缩减，最后回退基座。零残差跳过 IK，逐元素保留基座目标。非零解要求位置误差 ≤0.5 mm、姿态误差 ≤0.01 rad、关节限位、相对基座修正 ≤0.1 rad、相邻修正变化 ≤0.03 rad；块首目标跳变量不得比基座额外增加超过 0.03 rad。Replay 保留请求动作，实际执行及回退写入 xyz_execution.jsonl。

训练设置：100000 transition、40 秒回合、seed 20261024、预热 2000、batch 256、每条 transition 约一次 Critic 更新、gamma 0.995（控制步折扣）、Actor/Critic 学习率 1e-4/3e-4、初始 alpha 0.01 自动调节、无 shaping 或动作惩罚、探索概率 1。GPU 0 运行 VLA/Isaac，CPU 运行 SAC。回合边界检查预算，允许最后一回合超采集；replay 容量和更新目标为 100000。

输出：`outputs/astribot_online_rl/xyz010_raw_command_100k/`。源码快照、命令、job.json、日志、初始权重与训练产物均单独保存。每 1000 次更新在回合边界保存，20k/50k/最终额外保留完整 checkpoint/replay。`current` 原子切换发布匹配的 learner/replay；正常 SIGINT/SIGTERM 在完整回合与更新完成后保存，再关闭仿真。不自动重试或调参。停止监督进程时向当前训练子进程转发正常停止请求。

完成后同协议运行零残差基座与确定性 XYZ val-40，分别写入 eval_baseline、eval_xyz；不评旧 41041 保存点。监督脚本核验评估没有修改训练 learner/replay/status/protocol，并生成逐场景 paired_comparison.json。此实验同时改变动作空间与 Critic 表示，单种子结果不能分离二者贡献。

运行入口：`scripts/launch_astribot_xyz_experiment.py --output <独立实验目录> --existing-server-pid <本实验推理服务PID>`。必须先完成 CPU 与 Isaac 冒烟验收并启动同模型的 8799 端口推理服务。监督脚本管理该服务退出。该入口禁止复用已有 source 目录，以免覆盖实验。

验收记录：初次物理 FK 检查误用了 GPU 仿真的 USD 静态变换，已改为实际刚体位姿；复测误差约 2.58e-7 m。随后发现 transition journal 的旧 56 维硬编码，已显式支持 21/56 维并补充采集与评估路径测试。失败冒烟目录保留，不能算作成功训练。

## 每小时监测与用户授权恢复

用户随后明确要求每小时检查，训练意外终止则继续训练。因此本实验启用输出目录内 `hourly_watchdog.py`，替代原先每分钟只读监测；每 3600 秒记录一次进度至 `hourly_watchdog.jsonl`。上文“不自动重试”描述的是原启动器行为，此处为用户后续授权的覆盖。

仅在监督及训练子进程都已退出、预算未完成且没有人为停止标记时，从原源码快照和 `current` 原子发布的 learner/replay 保存点，用原参数加 `--resume` 恢复。恢复前核对源码身份、保存点文件和推理服务健康及模型身份，保留旧 job 和日志；不调参、不重置权重、不并行启动重复训练。恢复监督器继续执行原训练后的成对 val-40 流程。异常检查或恢复失败写入监测日志，下一小时重查。进程存活但卡住仅记录状态，不强制杀进程。

正常完成、`stop_requested` 或 `stopped*` 状态不触发恢复。人为停止时应先创建输出目录 `DISABLE_AUTO_RESUME` 文件或停止 `hourly_watchdog_process.json` 中的守护进程，再停止训练。已达到 100k 后不自动重启训练；验证阶段异常仅保留记录，需另行处理。后台监测记录到文件，不自动推送聊天通知。
