## 判断与限制

1. **只缩减案例、保留旧会话，还不足以纠正行为。** 第12轮改为下降，但仍错误声称腕图按钮在两指之间，并声称参照示范向下按压——本次选入的三条示范实际没有下降命令。第13–14轮继续前推。
2. **去除旧动作会话后，行为发生改变。** 三组都选择调整观察，而非直接前推。但没有一组生成手部向右的XYZ命令。
3. **仍存在相机与执行器关系的错误。** current_only第12轮理由把腕相机看不到按钮归因于头部俯仰，并提出通过转头解决；头部关节不改变腕相机相对手部的位置。其他头部角度的实际效果未在真机验证。
4. **不能视为任务成功或已经正确对齐。** 当前结果支持精简历史作为后续方向，但模型仍未可靠完成图像关系到手部动作的转换。单次条件测试不能证明稳定性。
