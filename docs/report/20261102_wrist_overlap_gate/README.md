# 腕图二维重叠门控：保存画面检查

本次按用户要求，只以**当前腕图中，白色箭头所指物理指端落入按钮可按区域的矩形框**作为正 X 前伸的检查条件，横向和纵向必须同时满足。通过后不设正 X 的 5 mm 上限，也不设置其他前伸距离上限。未通过时拒绝整条正 X 候选命令，不裁剪、不替换；负 X 后撤不依赖这项许可。

这是二维条件，不代表已完成三维接触对齐，也不代表按钮亮起或任务完成。

## 接线与执行规则

默认 `localized` 使用 `execution_policy=yz_alignment_before_forward`、`forward_guard_policy=wrist_tip_overlap`。先在 Y/Z 平面调整；提示词要求偏差明显且方向有依据时采用更大增量，可以同时调整 Y/Z，接近目标后再缩小步幅。粗调与精调不写死毫米数，也不依据未经标定的像素差机械生成位移。

每个正 X 候选都要检查。同一观测首次需要时调用独立腕图定位；同一观测内的修正候选可复用该次判读，但逐条核对完整命令。更换观测后旧许可失效。拒绝整条候选后，新的动作决策收到当前腕图检查依据，可以选择零 X 的 Y/Z 调整、头部/夹爪、重新观察、负 X 后撤或报告无法继续。不会截掉 X 后执行剩余分量。

许可同时在模型候选阶段、会话执行前和 HTTP 发送前核对，绑定当前观测与完整原始 XYZ；放行通过后没有额外步长上限。键盘执行器、机器人 HTTP schema、插值和发送完成语义保持不变。模型输出非法时仍可持续修正，停止后的迟到响应不能提交动作。新规则在下次原一键入口启动时加载，本次没有重启真机。

网页显示保存腕图中的按钮框与物理指端、横纵点入框结论及其观测 ID。旧版“横向位于两指之间”的历史记录保持原含义；新版拒绝候选记录为未执行。
