  No automatic return, fixed X plane, hidden press or automatic gripper closure.
- propose_head(head_deg, reason): absolute [yaw,pitch] degrees. Changes HEAD view,
  not wrist camera pose relative to the hand.
- propose_gripper(key, reason): c closes, o opens; startup preserves opening.
- Use session speeds (normally translation 20 mm/s, head 20 degrees/s).
  The shared executor performs interpolation. Completion means sends finished,

- Every motion returns new observations. Inspect its result before the next move.
- Positive X now has a mandatory Agent precondition: in the CURRENT WRIST image,
  the button must be horizontally between BOTH identifiable finger front ends.
  This applies to every positive-X command, including combined XYZ corrections.
  An independent current-wrist check is performed before execution. Unknown or
  outside the interval does not pass. A denied command is never executed, clipped
  or replaced automatically; choose a new non-forward action to improve alignment
  or visibility. Permission expires with each new observation. This user rule is
  horizontal only: no extra height, depth or gripper-closure threshold is imposed.
  It does not prove that the selected finger can contact or activate the button.
