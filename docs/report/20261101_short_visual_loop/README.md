## 实现内容

- [grounding.py](../../../src/pressb/agent_loop/grounding.py)：当前双图、8 个简短字段，描述可见性、头图接触手指、水平／高度偏差、腕图局部关系及灯态。没有案例、历史理由、框坐标、毫米指令或让模型回填的观测 ID；ID 由程序绑定。不可见却输出位置等字段冲突会被拒绝，允许修正一次。
- [short_loop.py](../../../src/pressb/agent_loop/short_loop.py)：保留任务、成功末三步、当前双图、上一实际命令与结果、上一判读和事件证据；过程图片及旧动作理由不继续累积。默认动作请求始终 5 图，当前判读始终 2 图。完整输入、输出、命令和观测仍保存。
- 动作模型多返回 `visual_basis` 与 `expected_effect`，检查它是否采用本轮判读及正确的执行部件。针对部分明确的“不可见却声称可见”理由增加检查。校验成功后去除这两个决策元数据字段，原始动作数值不变地交给旧执行器；原模型调用完整归档。**一致性检查不等于视觉事实正确，也不是完整自然语言语义证明。**
- 偏差改善只在相同头图手指、相近头部角度下比较类别。`unchanged_or_unresolved` 不表示实际没有移动，也不表示毫米误差没有变小。没有加入像素到毫米转换、指尖标定或未经验证的外参。
- 当前灯态从 off 到 on 时记录本次模型证据；若前一单帧灯态不确定、当前为 on，则按需独立核对前后四图。第一帧已经亮不能直接当作本次触发。
- 亮灯之后的负 X 移动，独立用前后四图核验可见退离；发送完成不能代替撤回。新手部移动会使旧撤回满足状态失效，历史记录保留。`report_done` 必须有本次亮灯和后续撤回证据并引用二者 ID。
- 原单指按压许可、无效深度／未确认触发时依据画面前推的许可仍在。没有限制 Y/Z、裁剪或拆分位移、强制闭爪、自动撤回或增加实测到位等待。
- 新格式为 `pressb-conversation-v3`。网页及失败案例读取同时支持旧 v1/v2；判读、亮灯核验、撤回核验中断而尚无动作请求时，明确记为未执行。

当前输入固定，因此预算默认仍为 65536，但不运行旧的长历史摘要压缩；首次精确计数，此后按可变文字的保守估算决定是否重新计数，超预算明确退出，不静默删案例。完整的原持续会话规则继续用于旧模式。
