# 三张单图像素链路探针

使用完全相同的短问题，分别输入最新第 5 轮头图原图、腕图原图及新生成的纯灰 JPEG。三个请求互相独立，没有相机标签、案例、历史理由、工具调用或机器人连接。`temperature=0`、`enable_thinking=false`、`max_tokens=256`。源图未编辑，灰图仅用于诊断。

| 输入 | 实际回答摘要 | 图像审查 |
|---|---|---|
| 头图 | 白色桌面；左右下方各一个黑色夹爪；按钮不可见 | 读到了夹爪与白色平面，但把面板称桌面，遗漏真实可见按钮 |
| 腕图 | 左上金属面板有向下箭头按钮；底部左右夹爪；标记不可见 | 按钮及夹爪位置基本符合，但遗漏明显白色箭头标记 |
| 纯灰图 | 纯灰背景；按钮、夹爪、标记均不可见 | 符合输入，没有沿用机器人场景 |

这组结果支持模型回答受到实际像素内容影响，可排除本组请求“完全没有输入图片”这一解释。它不能证明服务内部每个解码／缓存环节都没有问题，也不证明任意多图请求的关联全部正确。模型在识别按钮和标记方面仍有明显遗漏；不能把 `image_available=true` 的自述当成图像链路正确的证据。

三次请求均正常 `finish_reason=stop`，推理 token 为 0；累计约 29.24 秒，1572 输入 token、303 输出 token。完整内容见 [summary.json](summary.json)、[服务模型信息](models.json)，每个子目录保存请求与原始响应。执行脚本为 [probe_used.py](probe_used.py)。未重试挑选答案，未连接机器人。
