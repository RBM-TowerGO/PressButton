## 结论与边界

- 不能简单归因为模型完全看不懂当前图：专门问位置时，三个上下文条件都能识别明显横向偏差。
- 原动作决策受到历史动作及其错误对齐描述的影响；相同完整会话可以复现原错误。具体内部机制（注意分配、训练偏好、模型实现等）尚不能仅凭这些请求确定。
- 坐标方向转换也存在独立错误，不能把定位工具给出的next_axis直接当作执行命令。
- 单纯加一条“先看清楚再行动”没有修复；将独立定位结论显式提供给保留历史的动作模型，在这一帧使建议从+X前推变为-Y横移。
- 这是单帧、单次条件对照，不能证明稳定泛化或任务成功；-10mm幅度及动作效果未在真机验证。额外定位请求也会增加一次模型往返。

下一步值得验证的是明确分开当前观测判读与动作选择，让历史经验用于策略参考，并在动作理由中核对“目标方向→机器人方向→坐标符号”。本次没有给执行器增加限制，也没有自动修改在线流程。
