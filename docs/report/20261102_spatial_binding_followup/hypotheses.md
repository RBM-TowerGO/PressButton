# 实验前固定的待区分解释

本轮只使用保存图片和诊断变体，调用现有模型，不连接机器人执行动作。以下解释在本轮模型结果产生前固定，实验失败也不改写刺激或挑选答案。

| 解释 | 鉴别条件 | 可支持的结论 | 归因边界 |
|---|---|---|---|
| 对象／指定接触参照定位错误 | 分开只定位按钮、只定位物理端，返回一个点 | 哪个实体位置预测有误，误差是否足以颠倒左右顺序 | 输出坐标涉及视觉定位及坐标表达，不是直接读取模型内部位置 |
| 目标与参照角色绑定错误 | 标签颜色核对、分别定位T/P、正问／反问、交换字母后再次核对 | 角色交换是否正确传递到位置与关系 | 独立OCR正确不保证关系请求内部也正确读取了标签 |
| 回答画面左／右半边，而非指定参照关系 | 同尺寸灰底保留ROI，再平移同一ROI；点间偏差、大小保持 | 相对几何不变时，答案是否随画布位置改变 | 若变化，支持位置／参照条件敏感，不能唯一证明内部使用了图像中心 |
| 位置输出和关系输出不一致 | 同一响应同时返回两点与上下左右，由程序比较其自报坐标 | 可直接发现自报坐标与关系互相矛盾 | 即使自洽也不能证明点找对；单独定位与关系两次调用不能当作同一次内部状态 |
| 图像尺寸、场景范围或外部背景影响 | full1x/full2x/crop1x/crop2x；原尺寸灰化ROI外背景 | 分别观察尺度、裁切及背景移除的影响 | 放大是插值，不增加原始细节；服务可能自动缩放，token量不等于实际空间分辨率 |
| 显式数字关系计算错误 | 将本轮A两次单点预测作为纯文本输入，无图比较 | 相同数字事实下能否正确比较关系 | 点本身可能错；此项不验证识别、机器人坐标或三维接触 |

自然图定位使用预先划定的近似可接受区域，并报告连续误差。物理指端有语义范围，不能把助手选择的单个像素当作标定真值。归一化坐标统一为0–1000，横向向右、纵向向下，完全不涉及毫米或机器人动作。

不再上下翻转整个自然场景，避免把按钮向下符号翻成向上而产生目标语义变化。通过互换T/P身份和正反问法覆盖关系反向，颜色及几何位置保持固定。

全部请求独立、关闭thinking、只记录首次响应。格式非法、未知、自洽但定位错误、坐标与关系矛盾分别记录，不混为总体准确率。条件及适应性数字比较规则会在调用前写入plan.json。
