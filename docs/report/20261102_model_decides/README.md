# 默认 localized：将视觉判断交给模型

本次按用户要求移除程序依据视觉阈值决定动作是否合法的逻辑。20% 框尺度变化等阈值是先前实现加入的启发式条件，未经本场景实测标定。先前运行和报告保留原样；本次修改不代表真机任务已经成功。

## 当前流程

当前双图独立定位 → 整理原始坐标偏差与实际反馈 → 动作模型选择一个命令 → 原共享执行器。

- 移除按 20% 尺度变化、1° 头姿变化、1% 近零偏差、连续三次同向运动进行有效性或进展判定。
- 不再按 `partial/unknown` 禁用手部工具，不强制取景、异常复核或冲突恢复；移除必填 `visual_basis`。
- 取消正 X 的独立腕图横向放行条件。模型提出的原始 XYZ 通过现有命令解析后发送，不修改、裁剪、补撤回或补闭爪。
- 完成由动作模型判断，不再另发亮灯／撤回核验请求。提示词仍要求本次观察到按钮亮起及后续撤回；日志仍区分模型报告和人工确认。
- 每轮一次定位请求，不因坐标越界、可见性矛盾、额外字段或定位结构不完整反复修正。保留原始输出、可解析坐标及说明，交给动作模型判断。
- 程序仅整理两视角各自的坐标差和前后原始变化。部分可见框中心明确标为可见框中心，缺失数值不补历史位置，不将投影偏差解释为毫米量或三维接触。
- 保留 64K 会话预算、最近五轮和早期动作台账；压缩摘要容错读取，原始模型判断继续归档。不存在于本次运行的引用不加载图片，不伪造成有效引用。

仅保留必要的命令结构／数值解析、观测绑定、停止、单动作在途、命令幂等和采图失败不重放机制。可明确还原的 JSON 字符串数组（例如 `"[0,20,0]"`）在本地解析成同一组值，不额外请求模型。共享 SDK 执行器和机器人 HTTP schema 未改。

## 兼容与可见性

默认 localized 使用 `pressb-conversation-v5`、`pressb-localization-v2`，记录 `execution_policy=model_decides` 和 `forward_guard_policy=none`。网页展示原始定位、算术结果与模型判断，不展示新模式不存在的前推许可或可用视角门控。

显式选择 direct、separated、grounded 仍运行原对照逻辑。旧 v4 记录保持历史含义。默认成功示范最后三步、无失败案例、关闭 thinking 等既有选择不变。

## 验证

39 个相关测试文件共 **780 passed、3 skipped，耗时 50.38 秒**。机器可读结果见 [checks.json](checks.json) 和 [regression.xml](regression.xml)。回归覆盖定位不完整时仍提供全部工具、任意尺度／头姿变化不触发复核、正 X 无视觉许可直接进入原 HTTP 路径且 XYZ 不变、停止后迟到响应不执行、上下文工具调用配对、摘要容错、网页及新旧归档。

3 项跳过均由于环境缺少 Node。新增 v5 网页 DOM harness 另在工具 V8 中运行通过，检查新文案、原始输出、部分可见时的双图 SVG 偏差线及旧 v4 显示兼容；这是脚本与 DOM stub 检查，不是真实浏览器截图。其余两项跳过未另行重跑。

本次未调用真实模型，未连接或启动机器人。检查使用 fake 模型／SDK 和保存的归档结构；不能据此宣称定位质量或真机表现改善。
