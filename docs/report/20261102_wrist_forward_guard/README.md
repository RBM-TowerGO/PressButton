# 当前腕图横向条件控制前推

2026-11-02。用户明确选择：“只检查腕图中横向位于两指之间”。本次实现按此标准，不叠加头图、高度、测距或强制闭爪条件。

## 行为

- 默认约束三种Agent决策模式的所有正X候选动作，包括同时改变Y/Z的动作。键盘控制与共享执行器保持原有行为。
- 只有当前腕图里按钮可辨、两指前端可辨、按钮中心横向处于两指前端之间，三项独立判读均yes才放行。内侧边界允许单边指按压。unknown、no、缺失或旧观测证据不放行。
- 独立模型请求只含当前1张原始腕图、目标和观测ID；不输入头图、历史案例、动作理由、深度或候选动作。默认关闭thinking。
- 被拒绝的整条命令不发送、不裁剪、不自动替换。动作模型有一次机会重新选非前推动作；仍然非法则结束会话。检查请求失败或自身格式修正一次后仍失败也结束。
- 提交HTTP之前再次核对放行结果、观测ID、完整XYZ，防止跳过或复用失效检查。每个新观测重新判定；0/-X、转头、夹爪、观察不额外调用该模型。
- 网页显示“前推条件检查中/前推未放行/正X已放行”、当前观测、判读、图片数、token、耗时。每轮forward_guard目录保存完整过程；原始动作接口、数值精度、幂等与停止机制保持原有语义。
