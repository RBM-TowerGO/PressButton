## 修改

- `short_loop.py` 将当前判读渲染为双向关系：按钮在手指上方，等价于手指在按钮下方；仍明确标为同一模型判断，不产生新视觉证据。
- `alignment_control` 从实际历史命令计算各偏差持续观测数、Y/Z命令、无相应轴命令的间隔及轴方向往返，提醒检查长期未处理的偏差。它不衡量像素误差，也不把发送该轴命令当作纠正成功。
- 提示词对本装置通常直立面板视角给出“手指低→考虑+Z”的定性初始假设，允许以当前画面或已执行动作效果提出反证；没有像素毫米变换、固定补偿或执行器门控。
- 新 `decision_validation.py` 修复中英文否定可见性误判，并检查明确的按钮/手指主宾关系及动作词与XYZ符号矛盾。只要求模型修正一次，程序不替换、裁剪或重写动作。检查通过不等于视觉或策略正确。
- 单边手指、无效深度、未触发时有依据地前推仍允许；默认右指、动态低头、原动作接口与共享执行器保持原有语义。
- 旧动作和原始记录未覆盖；新增日志格式标记 `pressb-alignment-control-v1`。网页“运行记忆”可查看偏差记录。
