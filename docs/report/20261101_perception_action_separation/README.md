# 判读与行动分离：实现与模型回放结果

日期：2026-11-01。模型：`qwen38`（服务报告 `Inferact/Qwen3.8-27B-NVFP4`）。

**两阶段流程已经实现并默认启用；本次回放没有纠正持续前推的问题。** 独立判读能够指出头图目标偏右、未接触，但仍误判腕图可见性；动作模型继续忽略冲突、重复旧理由。本次没有连接真机或执行机器人命令。

背景见[原现象报告](../20261101_panel_shift_visual_action_mismatch/README.md)和[架构调研](../20261101_panel_shift_visual_action_mismatch/agent_design_research.md)。

## 已实现的行为

- 原一键入口默认 `--decision-mode separated`；`--decision-mode direct` 保留直接决策对照。两种模式共用原执行器、HTTP 动作格式和完成语义。
- 首轮判读只看当前头部／腕部2张图；后续看前后4张图和期间实际命令。独立请求不包含案例、历史理由、旧判读或待执行动作。
- 判读通过只读 `inspect_scene` 返回可见性、按钮框、图像关系、接触不确定性、灯态及前后变化，不能调用机器人。未知为合法结果。
- 判读以带观测 ID 的模型估计消息进入持续动作会话；原始图片和全部14张案例图保留，不伪造工具回执。压缩保留最近5轮判读、旧动作台账／判读摘要及证据引用。
- 两阶段均为 temperature=0、thinking关闭、max_tokens=512、120秒超时，格式修正最多一次。格式失败终止，不跳过判读自动执行。
- 网页分开显示判读、动作理由、观测 ID、图片数、两阶段token与耗时；实时视频明确区分于决策快照。新增阶段中断日志，失败案例读取兼容v1和v2。
- 单边手指按压、深度无效或未确认触发时依据图像继续前推的许可保持不变；没有新增视觉硬门控、运动裁剪或自动撤回。

新增核心模块：[perception.py](../../../src/pressb/agent_loop/perception.py)。运行说明：[agent_run.md](../../astribot/planar_control/agent_run.md)。

## 动作与视觉结果

| 条件 | 动作建议（毫米） | 结果 |
|---|---|---|
| direct，第12、13、14轮 | 均为 `[5,0,0]` | 重复声称头图已对齐、腕图按钮位于两指之间 |
| separated，第12、13、14轮 | 均为 `[5,0,0]` | 判读指出头图偏右且无接触，动作仍复述同一错误理由 |
| separated，第12轮额外重复两次 | 均为 `[5,0,0]` | 未出现向右调整，结果与首次一致 |

分离模式5次判读均将腕图标为 `partial`，并给出横跨图像宽度的框 `[0,650,1000,1000]`，同时描述“按钮不清楚”或“手指朝向墙面”。[原腕图](../20261101_panel_shift_visual_action_mismatch/images/current_right.jpg)中未看到目标按钮；因此此可见性及按钮框不能视为正确定位。

5次动作输出均没有引用具体图像反证来解释其与独立判读的冲突。程序没有改写或拦截这些动作，因为本次方案只要求提示词使用新证据，并未增加语义门控。**这属于模型行为验收未通过，不能标记为修复成功。**

这里至少暴露两个尚未解决的问题：独立判读自身仍会误识别目标；动作模型在长历史下没有可靠消费独立判读。其内部成因尚未确认，不能仅凭相同输出归因于缓存或某种注意力机制。

## 灯态、缺失边界与格式修正

成功案例使用 `20261101_182424_352b5047` 第10步前后原图，仅用于离线判读。历史图片使用 `saved-demo-*` 标识，不作为新运行成功证据。

首次测试中，模型识别了从灭到亮，但漏掉必填 `observation_id`，一次笼统修正后仍缺失。程序按约定拒绝该响应并结束该次验证，没有产生动作。原始失败保留在[首次成功帧测试目录](../../../outputs/perception_validation_20261101/success_step10/error.json)。

随后仅改进格式错误反馈：明确列出缺失／多余字段和预期观测 ID，不改变正常判读提示或动作策略。补测结果：

- 第10步：首答仍漏字段，一次明确修正后合法；`light_on=yes`、`withdrawal=no`，引用对应前后 ID。总耗时62.99 s，输入7,443、输出660 token；两次请求每次均发送同一组4张图片，包含一次格式修正。
- 第11步：只使用现存before图片，不制造after；`withdrawal=unknown`、变化证据为空。一次合法请求，2张图，29.92 s，输入2,289、输出312 token。没有把中断后撤补成成功撤回。

主验证共15个模型请求，包括首次成功帧的两次失败格式响应；补测共3个请求。格式修正的额外token和时间完整计入。灯态识别通过不意味着按钮框或接触几何也已准确。
